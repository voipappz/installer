VoIPAppz Offline Installer

Boot the disc, get a node. No internet.

Install

  1. Make a VM. 80 GB disk, 8 GB RAM, 4 CPU.

    Tick "Skip Unattended Installation" — otherwise VirtualBox installs its own machine instead of the node.

  2. Attach the ISO and start. 10–25 min of scrolling text, no questions. Long pauses are normal. Then it powers off by itself.
  3. Remove the disc, then start again. Settings → Storage → optical drive → Remove Disk from Virtual Drive.

    Leave it in and it reinstalls, wiping what it just built.

  4. Wait for first boot. A few minutes loading the node image. It stops at a login prompt saying leaving this node unconfigured — that's expected.

    Log in voipappz / voipappz. It forces a new password.

  5. Bring it up. 
    cd /opt/voipappz
sudo voipappz bootstrap

    Runs the setup wizard, starts the app, health-checks it. Nothing downloads.

  6. Seed both Kamailios. 
    sudo voipappz sbc ingress sync
sudo voipappz sbc egress sync

    Both. Separate stores — skipping the ingress 404s every call.

/usr/local/bin/voipappz

Plus Ubuntu 24.04.4 and 22 more packages. The CLI is there from the install; the images arrive on first boot.

If something looks wrong

long silencecopying 4.6 GB off the disc
powers offfinished — remove the disc
asks a questionVirtualBox's own installer is on; remake the VM
no wizardrun voipappz setup
"unconfigured"expected — it won't guess your domain
password rejectedexpired on purpose; set a new one
TLS warningsoffline can't get a real cert; voipappz cert confirms

Build a new ISO

make iso-payload    # once, ~60 min
make iso            # ~90 sec after that
ISO_DEST=where it lands
ISO_NETWORK=static IP instead of DHCP
-var installer_env=answer sheet — no login needed at all
