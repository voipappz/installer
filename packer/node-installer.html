VA-Crystal Node — Offline Installer

Boot the disc, get a machine that can install a node with no internet.

Restricted media. This disc carries a private container image; anyone who has it can extract that image. Do not copy or re-host it.

Install

  1. Make a VM. 60 GB disk, 8 GB RAM, 4 CPU.

    Tick "Skip Unattended Installation" — otherwise VirtualBox installs its own machine instead of the node.

  2. Attach the ISO and start. 10–20 min of scrolling text, no questions. Long pauses are normal — it is copying the image archive off the disc. Then it powers off by itself.
  3. Remove the disc, then start again. Settings → Storage → optical drive → Remove Disk from Virtual Drive.

    Leave it in and it reinstalls, wiping what it just built.

  4. Log in. voipappz / voipappz. It forces a new password.
  5. Install the node. 
    va-node-install

    That is the public installer, run against the image archive that came with the disc. It asks for a node name, the addresses, your mothership URL and an Account credential, then loads the image, registers the node and starts it.

    The image is offline; registration is not. This step has to reach your mothership. On a machine that cannot, run VA_REGISTER=0 va-node-install and register later.

  6. Check it. 
    docker exec va-voip voipappz health

What you end up with

$ which docker jq curl openssl
/usr/bin/docker
/usr/bin/jq
/usr/bin/curl
/usr/bin/openssl

$ cat /etc/va-crystal-node          # what this disc was
$ ls /var/lib/va-crystal/           # the image archive and the apt repo
$ docker ps --filter name=va-voip   # one container, after va-node-install

Ubuntu 24.04 plus Docker Engine and the four tools the installer uses. Nothing of a VoIPAppz mothership: no Postgres, no Kong, no admin, no API.

If something looks wrong

long silencecopying the image archive off the disc
powers offfinished — remove the disc
asks a questionVirtualBox's own installer is on; remake the VM
password rejectedexpired on purpose; set a new one
archive checksum failsthe disc or the copy is damaged; re-install from media
registration failsthe mothership is unreachable, or the Account credential is wrong
no va-node-installthis machine was not built from a node disc

Build a new ISO

make iso IMAGE_VERSION=2026.08.27-2 RELEASE_VERSION=2026.08.27-1

Or the Node ISO GitHub workflow, which mints the release version itself and publishes to S3. Two versions, deliberately: the image is va-crystal's number, the release is this disc's.

-var network=static IP instead of DHCP
-var with_image=falsea small disc; the installer must then reach a registry or S3
