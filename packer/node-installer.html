VoIPAppz Offline Installer

Boot the disc, get a node. No internet.

Install

  1. Make a VM. 80 GB disk, 8 GB RAM, 4 CPU.

    Tick "Skip Unattended Installation" — otherwise VirtualBox installs its own machine instead of the node.

  2. Attach the ISO and start. 10–25 min of scrolling text, no questions. Long pauses are normal. Then it powers off by itself.
  3. Remove the disc, then start again. Settings → Storage → optical drive → Remove Disk from Virtual Drive.

    Leave it in and it reinstalls, wiping what it just built.

  4. Wait for first boot. A few minutes loading the node image. It stops at a login prompt saying this machine is not a node yet — that's expected.

    Log in voipappz / voipappz. It forces a new password.

  5. Make it a node. 
    sudo va-node-install

    Asks for a node name, its addresses, your mothership URL and an Account token, registers the node and starts it. The image is already on the disk — nothing downloads.

    Registration has to reach your mothership. With none in reach: sudo va-node-install --no-register, and register later.

What you end up with

$ systemctl is-enabled voipappz-node
enabled                 # the node starts at every boot

$ docker ps --format '{{.Names}}  {{.Image}}'
va-voip  nirlevi/va-crystal:<version>

$ sudo voipappz health
# the node's own verdict; names anything that is down

$ cat /etc/voipappz-image
# which disc, which node image, which CLI

Plus Ubuntu 24.04.4, Docker, sngrep, tcpdump, ufw (installed, not enabled) and the usual triage tools. The same commands are printed at every login.

If something looks wrong

long silencecopying the node image off the disc
powers offfinished — remove the disc
asks a questionVirtualBox's own installer is on; remake the VM
"not a node yet"expected — run sudo va-node-install
password rejectedexpired on purpose; set a new one
image missingjournalctl -u voipappz-loadimages
node not runningsystemctl status voipappz-node, docker logs va-voip
firewallufw is off; before enabling it allow 5060 udp+tcp, 5070, 5090, 4000, 8090, 9060/udp and RTP

Build a new ISO

make iso            # stages the node image if it moved, then cuts
make iso-upload     # versioned + latest + sha256, private
VA_VOIP_IMAGE=which node image; add VOIPAPPZ_LOCAL_IMAGES=1 for a local build
ISO_DEST=where it lands
ISO_NETWORK=static IP instead of DHCP
-var installer_env=an install.sh answer file — no login needed at all
